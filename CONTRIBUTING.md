# Contributing to Mini-Project

Thank you for your interest in contributing to **Mini-Project**! We welcome contributions, bug reports, and feature ideas.

## 📜 Code of Conduct

Please maintain a respectful, constructive, and friendly environment for everyone.

## 🛠️ How to Contribute

1. **Fork the Repository** on GitHub.
2. **Clone your Fork** locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Mini-Project.git
   cd Mini-Project
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make Your Changes**:
   - Follow the **Docs-First Workflow** (`CLAUDE.md`, `docs/RULES.md`).
   - Keep code modular and documented.
5. **Test Your Changes**:
   - Verify that your changes build and run without console errors.
6. **Commit & Push**:
   ```bash
   git commit -m "feat: description of your feature"
   git push origin feature/your-feature-name
   ```
7. **Submit a Pull Request** describing your changes and motivation.

## 🐞 Reporting Bugs

If you find a bug, please open a GitHub Issue using our Bug Report template. Include:
- Operating system and browser details
- Clear steps to reproduce the issue
- Expected vs actual behavior

Thank you for helping make Mini-Project better!
