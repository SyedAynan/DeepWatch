# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do **not** open a public GitHub issue.

Instead, please send an email to the repository owner or submit a private security advisory through GitHub.

We will acknowledge receipt within 48 hours and work with you to resolve any reported security concerns promptly.
