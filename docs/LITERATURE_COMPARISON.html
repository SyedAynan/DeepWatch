How to read this table. Column "Limitation vs this project" states what each paper does not cover relative to DeepWatch's unified scope (detection + audio-video fusion + attribution + explainability + forensic integrity). It is a scope/capability comparison, not a criticism of the papers' quality - the base papers are the foundation we build on. ★ = IEEE-flagged venue.
